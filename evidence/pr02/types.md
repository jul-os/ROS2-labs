# PR02 — Типы сообщений ROS 2

## Основные топики

| Топик | Тип | Назначение |
|-------|-----|------------|
| `/turtle1/cmd_vel` | `geometry_msgs/msg/Twist` | Команда скорости черепахи |
| `/turtle1/pose` | `turtlesim/msg/Pose` | Текущая поза черепахи |

---

## geometry_msgs/msg/Twist

Сообщение для управления скоростью.

### Поля

```
Vector3 linear
  float64 x  # линейная скорость по X (м/с)
  float64 y  # линейная скорость по Y (м/с)
  float64 z  # линейная скорость по Z (м/с)
Vector3 angular
  float64 x  # угловая скорость по X (рад/с)
  float64 y  # угловая скорость по Y (рад/с)
float64 z  # угловая скорость по Z (рад/с)
```

### Пример

```
{linear: {x: 1.0}, angular: {z: 0.5}}
```

Движение вперёд с поворотом против часовой стрелки.

---

## turtlesim/msg/Pose

Сообщение с текущим положением черепахи.

### Поля

```
float32 x        # координата X (м)
float32 y        # координата Y (м)
float32 theta    # угол поворота (рад)
float32 linear_velocity   # линейная скорость
float32 angular_velocity  # угловая скорость
```

---

## Почему правильного типа недостаточно

Даже если тип сообщения (`geometry_msgs/msg/Twist`) правильный, доставка не происходит, если топик не совпадает. DDS (распределённый сервис данных) ищет соответствие по **полному имени топика** и **типу сообщения**. Ошибка в имени `/cmd_vel` вместо `/turtle1/cmd_vel` означает, что издатель и подписчик работают с разными топиками и не находят друг друга.

---

## Обнаружение vs доставка

- **Обнаружение** (discovery): DDS находит участников сети и их топики. Издатель на `/cmd_vel` виден через `ros2 topic info`.
- **Доставка** (delivery): сообщения передаются только если у топика есть и издатель, и подписчик с совпадающим именем и типом.
